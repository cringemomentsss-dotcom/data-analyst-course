# База проекта: «Поток»

Генерируется скриптом, в git попадает только код.

```bash
make stream
```

Поднимает схему `stream` в базе `casino` и заливает данные. Пересобрать — та же команда, схема пересоздаётся с нуля.

Подключение то же: `localhost:5433`, база `casino`, пользователь `analyst`. Не забудь `SET search_path TO stream;`.
