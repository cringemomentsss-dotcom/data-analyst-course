# Грязные выгрузки «Секретов Темнолесья»

| Файл | Строк | Зернистость |
|---|---|---|
| `igroki.csv` | 12 130 | игрок |
| `pokupki.csv` | 8 056 | покупка |

Получены из схемы `game` (та же игра, что в спринте 4) и намеренно испорчены так, как портятся настоящие выгрузки: смешанные форматы дат, числа строками с валютой и запятой, пропуски пятью разными способами, дубликаты, неконсистентные категории.

Пересобрать (нужен поднятый `make game`):

```bash
python3 sprint-08-pandas/data/make_dirty.py
```

Чистые данные для сверки лежат в базе — но подглядывать туда до сдачи не надо: смысл проекта в том, чтобы восстановить их из грязной выгрузки. Эталонные числа для самопроверки есть в ТЗ проекта.
