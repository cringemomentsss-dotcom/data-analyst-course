# Датасет: рынок общепита Москвы

`zavedeniya.csv` — 10 660 строк, одна строка = одно заведение. Данные синтетические, детерминированные.

Пересобрать: `python3 generate_food.py`

Дефекты внесены намеренно: пропуски тремя способами (`''`, `н/д`, `нет данных`), категории в разном регистре, `Тёплый Стан` / `Теплый Стан` и `Хорошёво-Мнёвники` / `Хорошево-Мневники`, 160 дубликатов, физически невозможные значения мест, чека и рейтинга.

Эталонные числа для самопроверки — в ТЗ проекта.
