# Проект спринта 5. Дашборд по данным TED

## Что это за задание

Проект с ревью и **жёстким ТЗ**. Отличие от предыдущих проектов принципиальное: здесь ты не формулируешь задачу, а исполняешь спецификацию.

Это отдельный навык, и он нужен чаще, чем кажется: заказчик приходит с готовым списком требований, и от аналитика нужно, чтобы дашборд соответствовал им точно, а не «примерно, но красивее». Право предложить улучшение у тебя есть — но сначала выполняется требование, а предложение идёт отдельным пунктом.

## Данные

Три файла в `../data/`, кодировка UTF-8:

**`ted_talks.csv`** — 2 750 строк, одна строка = одно выступление.

| Поле | Что |
|---|---|
| `talk_id` | идентификатор |
| `title` | название |
| `speaker` | спикер |
| `speaker_occupation` | профессия; у 197 не заполнена |
| `num_speakers` | число спикеров |
| `event` | название события |
| `event_year` | год события |
| `event_city` | город |
| `is_main_conference` | 1 — основная конференция TED, 0 — сателлит |
| `recorded_date` | дата записи |
| `published_date` | дата публикации |
| `duration_sec` | длительность; у 9 записей 0 |
| `views` | просмотры |
| `comments` | комментарии |
| `languages` | число языков перевода |

**`ted_tags.csv`** — 8 385 строк, связь «многие ко многим»: `talk_id`, `tag`, `category`. У выступления от 1 до 5 тегов. Есть дубликаты.

**`ted_ratings.csv`** — 36 644 строки, длинный формат: `talk_id`, `rating`, `votes`. Четырнадцать типов оценок, девять положительных: Inspiring, Informative, Fascinating, Persuasive, Beautiful, Courageous, Funny, Ingenious, Jaw-dropping. Пять остальных: Longwinded, Unconvincing, Obnoxious, Confusing, OK.

## Техническое задание

Один дашборд, название **«TED: обзор выступлений»**. Размер — фиксированный 1200 × 900, не автоматический.

### Строка ключевых показателей (верх дашборда)

Четыре числа крупным шрифтом, в одну строку:

1. **Выступлений** — число уникальных выступлений.
2. **Просмотров** — суммарные просмотры, в формате «8,5 млрд».
3. **Медиана просмотров** — в формате «1,7 млн».
4. **Средняя длительность** — в минутах с одним знаком, записи с нулевой длительностью исключить.

### График 1. Динамика публикаций

Линейный график. По оси X — месяц публикации (непрерывная ось). По оси Y — число выступлений. Заголовок формулирует вывод, а не тему.

### График 2. Просмотры по категориям

Горизонтальная столбчатая диаграмма, отсортированная по убыванию просмотров.

Каждое выступление учитывается в каждой своей категории **один раз**. Правильные значения:

| Категория | Просмотры |
|---|---|
| Общество | 5 158 153 055 |
| Технологии | 3 340 974 059 |
| Наука | 2 997 904 073 |
| Образование | 2 382 902 717 |
| Искусство | 2 306 491 883 |
| Экология | 1 897 894 871 |
| Бизнес | 1 794 092 418 |
| Здоровье | 1 276 285 438 |
| Дизайн | 1 224 118 074 |

Если у тебя другие числа — ты попал в ловушку размножения строк, см. часть 5 теории.

В подписи под графиком должно быть сказано, что суммы по категориям пересекаются, потому что выступление относится к нескольким.

### График 3. Топ-10 выступлений

Таблица или горизонтальные столбцы: название, спикер, просмотры. Отсортировано по убыванию просмотров.

Первые пять для проверки:

| Просмотры | Название |
|---|---|
| 74 000 000 | Почему роботы недооценены |
| 68 930 142 | Отчего роботы говорят правду |
| 49 344 433 | Что леса опаснее, чем принято думать |
| 38 014 523 | Отчего вода опаснее, чем принято думать |
| 37 065 907 | Как энергия нуждаются в защите |

### График 4. Длительность и просмотры

Точечная диаграмма: X — длительность в минутах, Y — просмотры. Одна точка — одно выступление. Ось Y в логарифмической шкале. Записи с нулевой длительностью исключить.

В заголовке — ответ на вопрос, есть ли связь между длительностью и просмотрами.

### График 5. Структура оценок

Горизонтальная столбчатая: четырнадцать типов оценок по суммарному числу голосов, по убыванию. Положительные и отрицательные типы различаются цветом.

Всего голосов для проверки: **4 677 956**. Три самых частых типа: Funny (428 051), Ingenious (420 561), Informative (419 399).

### Фильтры

Три фильтра, действующие на все графики дашборда:

1. **Год события** — диапазон.
2. **Категория** — множественный выбор.
3. **Только основная конференция** — переключатель по `is_main_conference`.

Фильтры размещены в одном месте, подписаны по-русски, у каждого понятно, что он делает.

### Требования к оформлению

- Ни одной круговой диаграммы, ни одного объёмного или градиентного элемента.
- Все оси подписаны, единицы измерения указаны.
- Крупные числа сокращены до тысяч, миллионов, миллиардов.
- Единая палитра на весь дашборд.
- Заголовок каждого графика формулирует вывод, а не тему.
- Тултипы отредактированы: не больше четырёх полей, текст человеческий.
- Ни одного листа с названием «Sheet 1».

## Ловушки

Их в этом задании четыре, и три из них дают правдоподобно выглядящую, но неверную цифру:

1. Соединение с тегами завышает просмотры втрое.
2. Девять записей с нулевой длительностью занижают среднюю длительность и портят точечную диаграмму.
3. Одно событие записано двумя способами и разбивается надвое в разрезах.
4. Шестьдесят шесть дублей в тегах слегка завышают показатели по категориям.

Проверяй себя порядком величины. 8,5 миллиарда просмотров на 2 750 выступлений — это 3 миллиона на выступление, правдоподобно для TED. 26 миллиардов — это 9,5 миллиона на каждое, что неправдоподобно, и это должно насторожить раньше, чем ты полезешь искать ошибку.
