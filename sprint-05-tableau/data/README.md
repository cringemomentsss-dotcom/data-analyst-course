# Датасет TED

Три CSV, кодировка UTF-8 с BOM (Tableau и Excel читают без настроек).

| Файл | Строк | Зернистость |
|---|---|---|
| `ted_talks.csv` | 2 750 | выступление |
| `ted_tags.csv` | 8 385 | выступление × тег |
| `ted_ratings.csv` | 36 644 | выступление × тип оценки |

Данные синтетические, детерминированные. Пересобрать: `python3 generate_ted.py`.

Связь: `ted_tags` и `ted_ratings` соединяются с `ted_talks` по `talk_id`. Обе — «многие к одному», поэтому физический join размножает строки. Подробно — часть 5 теории спринта.

Эталонные числа для самопроверки — в теории спринта и в ТЗ проекта.
