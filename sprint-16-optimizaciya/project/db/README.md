# База проекта: витрина «Поток+»

```bash
make dwh
```

Поднимает схему `dwh` в базе `casino`. Не забудь `SET search_path TO dwh;`.

Генерация идёт **прямо в базе** через `generate_series`, без промежуточных CSV:
восемь миллионов строк выгрузкой в репозиторий не кладутся. Занимает около двух
минут и **1,5 ГБ** на диске.

Случайность зафиксирована через `setseed(0.42)` — данные воспроизводимы.

| Файл | Что делает |
|---|---|
| `schema_dwh.sql` | таблицы без индексов, кроме первичных ключей |
| `load_dwh.sql` | генерация данных, затем три индекса и `ANALYZE` |

Индексы создаются **после** вставки: строить их по ходу загрузки в разы дольше.

Набор индексов намеренно неполный — чего не хватает, выясняется в проекте.
