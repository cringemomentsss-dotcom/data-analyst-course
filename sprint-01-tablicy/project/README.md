# Проект спринта 1. Отчёт для сети барбершопов

## Постановка от заказчика

Владелец сети из трёх барбершопов прислал выгрузку из CRM за полгода и написал:

> «Посмотри, пожалуйста, что там по мастерам и вообще. Хочу понять, кого премировать и стоит ли открывать четвёртую точку. И вроде по будням пусто, может смены переделать?»

Это типичная постановка: три разных вопроса в одном абзаце, ни одного определения, и скрытое допущение («по будням пусто»), которое нужно проверить, а не принять на веру.

## Данные

`../data/zapisi-barbershop.csv`, 2 880 записей, январь — июнь 2026.

| Столбец | Что это |
|---|---|
| `id_zapisi` | идентификатор записи |
| `data` | дата |
| `vremya` | время начала |
| `filial` | филиал |
| `master` | мастер |
| `usluga` | услуга |
| `cena` | цена |
| `id_klienta` | клиент |
| `kanal_zapisi` | как записался |
| `status` | выполнена / отменена / неявка |

Выгрузка грязная. Это не ошибка датасета — так выглядит реальная выгрузка из CRM, куда администраторы вводят руками.

## Что сделать

**1. Превратить просьбу в задачи.** Выпиши список конкретных вопросов, на которые ответишь, и определения, которые принял (что считаем выручкой, какой период, как поступаем с отменами). Это первый лист отчёта.

**2. Очистить данные.** Отдельным листом, исходник не трогать. Как минимум разобраться с: типами цены, форматами дат, неявными дубликатами в именах мастеров и филиалов, явными дубликатами записей, пропусками в услугах, статусами. По каждому решению — короткий комментарий, почему так.

**3. Посчитать:**
- выручку по мастерам, филиалам, услугам, месяцам;
- средний и медианный чек, и объяснить разницу;
- загрузку по дням недели и часам;
- долю отмен и неявок — по мастерам и по каналам записи;
- долю повторных клиентов и их вклад в выручку;
- динамику по месяцам.

**4. Проверить гипотезу заказчика** про пустые будни. Она может оказаться верной, неверной или верной частично — по филиалам.

**5. Сделать 4–6 визуализаций** под конкретные вопросы.

**6. Написать выводы.** Первым листом. Пять пунктов максимум, каждый — действие, а не наблюдение.

## Критерии приёмки

Обязательные:

- [ ] Есть лист с постановкой: вопросы и принятые определения, до расчётов.
- [ ] Исходные данные сохранены нетронутыми, очистка на отдельном листе.
- [ ] Ни одной цифры, вбитой руками — всё считается формулами от исходных данных.
- [ ] Цена приведена к числу; `COUNT` по столбцу цены совпадает с `COUNTA`.
- [ ] Даты приведены к единому типу, группировка по месяцам работает.
- [ ] Мастера сведены к 8, филиалы к 3. Метод сведения виден в файле.
- [ ] Явные дубликаты найдены, решение по ним обосновано в комментарии.
- [ ] Отменённые и неявки исключены из выручки — или включены с явным обоснованием.
- [ ] Есть и средний, и медианный чек, разница объяснена словами.
- [ ] Гипотеза про будни проверена данными, ответ однозначный.
- [ ] Минимум 4 графика, каждый отвечает на заявленный вопрос, ни одного кругового.
- [ ] Заголовки графиков — выводы, а не темы.
- [ ] Лист «Выводы» первый, максимум 5 пунктов, каждый сформулирован как действие.
- [ ] Файл открывается по ссылке на просмотр.

Желательные:

- [ ] Сводные вместо ручных группировок там, где это уместно.
- [ ] Именованные диапазоны вместо `$A$2:$B$20`.
- [ ] Есть оценка потенциала хотя бы для одной рекомендации в деньгах.
