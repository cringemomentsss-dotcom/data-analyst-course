## Как запустить

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
make db          # поднять PostgreSQL и залить базу курса
make check       # убедиться, что 15 таблиц на месте
```

Подключение: `localhost:5433`, база `casino`, пользователь `analyst`, пароль `analyst`, схема `casino`.

```bash
make test SPRINT=07          # или 08, …, 20, 21

```

## Про Tableau Public

Tableau Public подключается только к файлам — `.csv`, `.xlsx`, `.tsv` и Google Таблицам. **К базам данных он не подключается**, это возможность платного Tableau Desktop. Поэтому цепочка в модуле 2 такая:

```
PostgreSQL → SQL-витрина → CSV → Tableau Public → дашборд
```

Выгрузка: `make export SQL=путь/к/витрине.sql OUT=путь/к/файлу.csv`

И правило курса: Tableau Public сохраняет книги только в публичное облако, приватных черновиков не бывает. Никаких реальных данных — только учебные и открытые датасеты.
