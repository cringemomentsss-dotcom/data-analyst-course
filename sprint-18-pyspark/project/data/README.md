# Сырые логи проекта: генерация и заливка

```bash
make s3
```

Генерирует логи и заливает их в MinIO. Около двух минут, ~50 МБ.

| Что | Значение |
|---|---|
| Событий | ~2 040 000 |
| Партиций | 30 (июнь 2026) |
| Формат | JSON Lines, gzip |
| Путь | `s3a://raw/events/dt=YYYY-MM-DD/part-000.json.gz` |
| Справочники | `s3a://raw/dicts/{users,products}.csv` |

Случайность зафиксирована (`SEED = 18`) — данные воспроизводимы.

Файлы кладутся в `out/` и **не попадают в репозиторий**: папка в `.gitignore`.
Нужны заново — просто перезапусти `make s3`.

Перечень намеренных дефектов — в `../README.md`, раздел «Что в данных не так».
