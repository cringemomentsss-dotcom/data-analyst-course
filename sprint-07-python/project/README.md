## Про таблицу соответствий

`normalize_name` приводит регистр и пробелы — этого хватает, чтобы свести `Иван Петров`, `иван петров` и ` Иван Петров `. Но `Иван П.` автоматикой не сводится ни с чем: машина не знает, что это тот же человек.

Поэтому нужна **таблица соответствий**, написанная руками:

```python
MASTER_ALIASES = {
    "иван п.": "иван петров",
    "тимур а.": "тимур аскеров",
    "д. ким": "данила ким",
}
```

Это не костыль, а нормальная часть работы: где автоматика не справляется, решение принимает человек и фиксирует его в коде. Важно, что оно **зафиксировано** — а не «я тогда вручную поправил в таблице».

И вот в чём цена вопроса. До сведения Иван Петров с выручкой 401 755 стоит на четвёртом месте. После — 598 405 и первое место. Если бы владелец премировал по такому отчёту, он премировал бы не того.
