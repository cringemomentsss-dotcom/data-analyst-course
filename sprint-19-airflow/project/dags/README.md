# Папка DAG-ов

Смонтирована в контейнер Airflow как `/opt/airflow/dags`. Всё, что положишь
сюда, Airflow подхватит сам — файл появится в списке в течение полуминуты.

| Файл | Что это |
|---|---|
| `demo_taskflow.py` | демонстрационный DAG: TaskFlow, логическая дата, retry. Не решает проект, показывает механику. Не трогай |
| твои файлы | DAG проекта |

```bash
make air                              # поднять Airflow, UI на localhost:8080
make air-cli CMD='dags list'          # список DAG-ов
make air-cli CMD='dags list-import-errors'   # почему файл не подхватился
make air-cli CMD='tasks test мой_dag моя_задача 2026-06-05'   # прогон одной задачи
```

`tasks test` — самый быстрый цикл отладки: запускает задачу с указанной
логической датой, ничего не пишет в метабазу, выводит логи прямо в консоль.

Вход в UI: `analyst` / `analyst`.
