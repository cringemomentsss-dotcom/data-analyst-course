# База проекта: перенос «Поток+» в ClickHouse

```bash
make dwh   # сначала схема dwh в PostgreSQL, если ещё не поднята
make ch    # поднять ClickHouse и перенести данные
```

Загрузка идёт **напрямую из PostgreSQL** табличной функцией `postgresql()`,
без промежуточных CSV. Функция ходит в соседний контейнер по имени сервиса
`postgres` — это работает, потому что оба контейнера в одной сети compose.

| Файл | Что в нём |
|---|---|
| `schema_ch.sql` | **эталонная** схема — не открывай, пока не спроектируешь свою |
| `load_ch.sql` | перенос четырёх таблиц из PostgreSQL |

ClickHouse поднимается профилем `module6`: `docker compose up -d` без профиля
его не трогает, и остальной курс работает как раньше.
