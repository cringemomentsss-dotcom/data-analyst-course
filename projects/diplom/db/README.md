# Данные для диплома

```bash
python3 download_nyc.py --months 2024-01 2024-02 2024-03
python3 download_nyc.py --year 2024
```

Открытые данные комиссии по такси Нью-Йорка. Регистрация не нужна.

| | |
|---|---|
| Один месяц | ~48 МБ, ~3 млн поездок |
| Год | ~570 МБ, ~40 млн поездок |
| Формат | Parquet |

Файлы кладутся в `raw/` и **в репозиторий не попадают** — папка в `.gitignore`.

Свежие месяцы публикуются с задержкой около двух месяцев: запрос на
позавчерашний месяц вернёт ошибку, и это не поломка скрипта.

Справочник зон (265 зон с районами) скачивается отдельно с сайта TLC.

Альтернативные датасеты и требования к своему выбору — в `../README.md`.
