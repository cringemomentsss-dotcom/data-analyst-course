# База проекта: BitMotion Kit

```bash
make shop
```

Поднимает схему `shop` в базе `casino`. Не забудь `SET search_path TO shop;`.

Внутри — эксперимент `exp_site_v2` (новая версия сайта, 6 апреля — 31 мая 2026). Дефекты внесены намеренно: 180 задвоенных заказов, 1 154 группы задвоенных событий, 260 сессий нулевой длительности, пропуски в стране.
