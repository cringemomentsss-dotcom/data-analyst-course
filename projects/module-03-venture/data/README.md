# Датасет: венчурные сделки

Пять связанных CSV, период 2014 — июнь 2026. Данные синтетические, детерминированные.

| Файл | Строк | Зернистость |
|---|---|---|
| `companies.csv` | 8 000 | компания |
| `rounds.csv` | 12 676 | раунд |
| `investors.csv` | 4 000 | инвестор |
| `investments.csv` | 33 712 | раунд × инвестор |
| `acquisitions.csv` | 945 | поглощение |

Пересобрать: `python3 generate_venture.py`

Дефекты внесены намеренно: три формата даты (разделитель указывает формат), деньги в четырёх записях включая суффикс `M`, 26 вариантов написания 13 категорий, пропуски, 131 дубликат раунда, 105 раундов раньше основания компании, расхождение между статусом `acquired` и таблицей поглощений.
